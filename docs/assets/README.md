# Screenshots

Images in this folder are shown on the dashboard (GitHub Pages serves `docs/`)
and in the repo README. Each one is optional: the dashboard hides a missing
image instead of showing a broken one.

| File | What to capture |
|---|---|
| `phoenix-trace.png` | One trace open in Phoenix: the span tree plus the Annotations panel. The "Are there any violations…" trace shows the false pass best. |
| `phoenix-annotations.png` | The project's span list, with the annotation averages (`llm_judge…` vs `deterministic_verdict`) visible. |
| `side-by-side.png` | The `SIDE-BY-SIDE` block that `demo_phoenix_evals.py` prints. |
| `trace-clean.png` | The trace for "What year was Coney Island Beach…". Shown in the dashboard's *Clean answer* scenario. |
| `trace-zero.png` | The trace for "Are there any violations…". Shown in the *Zero-Sources* scenario. |
| `trace-dropped.png` | The trace for "When was Omer Fast's The Casting made?". Shown in the *Dropped system prompt* scenario. |
| `dashboard.png` | The deployed dashboard at desktop width, for the README. |

Wide PNGs (about 1600 px) read well. Crop out browser chrome and anything
personal, such as other tabs or bookmarks.
